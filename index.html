Sobre a Solução
Plataforma corporativa de Cloud Security desenvolvida para monitoramento contínuo, governança, análise de vulnerabilidades, compliance e simulação de ameaças em ambientes AWS. A solução integra um painel interativo em Streamlit com um back-end corporativo em Node.js.
Módulos Monitorados
✓ IAM & S3 Security
✓ EC2 Hardening & Security Groups
✓ AWS Config & Compliance
✓ Lambda & RDS Security
✓ GuardDuty Threat Intelligence
✓ Attack Path Analysis
Tecnologias Utilizadas
Python Node.js / Express AWS Cloud Streamlit GitHub Security Hub GuardDuty IAM & EC2 S3 & RDS Lambda & KMS
Arquitetura da Solução
Frontend: Streamlit (Python)
Backend: Node.js / Express (API REST)
Infraestrutura & Segurança: AWS Cloud Services
Versionamento: Git / GitHub
Deploy: Streamlit Cloud + Render
